# Roadmap

- **Screenshots.** Overview (Exposé) and a GIF of the gestures.
- **One installer with rollback.** Every component, the settings from `reference/`
  and the theme SVG edits in one script that backs up what it changes.
- **Theme SVG edits as a script** instead of the manual steps in TUNING.md.
- **Automatic rebuild after KWin upgrades.** An apt hook that rebuilds `liquidglass`
  (with the patch), KDE Rounded Corners and InputActions, and tells the user to log
  out and in.
- **Free fonts.** Replace SF Pro / SF Mono with openly licensed faces so a complete
  system can be redistributed.
- **Clean-system test.** Run the whole install on a fresh Kubuntu in a VM.
- **Light theme.** Everything is tuned for the dark variant only.
